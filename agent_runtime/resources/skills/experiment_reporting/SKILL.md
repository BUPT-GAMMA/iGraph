# 实验报告

## 适用场景
用于用户请求报告、摘要、实验记录或可复现结果说明时。

## 操作步骤
1. 说明图或数据集背景。
2. 总结方法和工具调用序列。
3. 汇报关键指标和结果。
4. 说明假设、局限性和建议的后续检查。
