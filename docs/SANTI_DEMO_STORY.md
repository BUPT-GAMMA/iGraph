## 故事主线

**核心问题：三体舰队尚未抵达，人类已经为“怎么活下去”产生分歧。**

1. **背景与防御**：危机纪年第 3 年，三体舰队距太阳系 4.21 光年。人类仓促建设太空军；吴岳看见技术差距而悲观，章北海强调信念与人的作用。
2. **逃亡争议**：只能带走少数人时，“谁走谁留”比造飞船更难。史晓明借此向张援朝兜售假“逃亡基金”；真正的联合国 117 号决议宣布逃亡主义非法。
3. **敌方与悬念**：三体主通过智子重新联系 ETO，忌惮人类能隐藏思想，并要求其破解面壁计划。罗辑遭遇车祸后被史强严密护送，原因在这份节选中尚未揭晓。
4. **结尾**：章北海在太空军会议上当众指出吴岳的失败主义；吴岳承认，其他军官质疑章北海的做法。故事停在这个冲突上。

**一句收束**：这段节选真正追问的是，在几百年后才有结果的战争面前，人类怎样分配生存机会、相信什么、由谁承担今天的代价。

## 现场提问（图分析主线）

1. **看全图**：当前图有多少节点、关系？运行连通性分析，弱连通分量与强连通分量各有多少，最大分量占全图多少？这说明故事线之间连接得怎样？
2. **找核心人物**：分别计算度中心性和介数中心性前五名。罗辑、史强、章北海的排名为什么不同？请把人物与“太空军”等泛称节点分开解释。
3. **找故事群落**：运行 Louvain 社区检测，列出最大的三个社区、规模和代表节点。它们分别对应护送罗辑、民间逃亡争论、太空军分歧中的哪条线？小社区是否显示了抽取碎片？
4. **查真实路径**：在有向图中，张援朝能否到达罗辑？分别检查张援朝→史强、史强→罗辑，逐边给出关系和方向。不要因为“史晓明”与“史强”同姓就补出亲属关系。
5. **展开局部关系**：史强与罗辑是否直接相连？有多少条并行关系？两人的一跳局部图是否存在共同邻居？未核实的节点名称和方向要明确说明。
6. **回到原文核对**：检查“史晓明—逃亡基金—张援朝”和“三体主—智子—ETO”的边及来源片段。哪些是人物话术，哪些是原文事实？图里缺失的因果关系要明确说未知。

**实测备忘**：55 个弱连通分量、268 个强连通分量，最大弱分量 41 节点；度中心性前三为史强、罗辑、章北海，介数中心性最高为章北海；Louvain 检出 58 个社区；张援朝→罗辑不可达，史强→罗辑可达（1 跳、6 条并行边）。
