## 新增功能

- 独立构图工作台：从个人数据集选择 SQL、CSV、TXT 源文件，进入构建、状态查看、编辑和保存流程，支持返回已有构图结果。
- Graph Schema：将实例图聚合为节点类型和关系类型，显示实例数量、关系数量、属性路径及属性类型；Schema 查看与实例级编辑各自管理选中状态。后端接口不可用时可从已加载实例图生成本地结果。
- 智能概览：结合节点类型、社区、度数和代表节点之间的路径选取展示样本；区分上游返回不完整与浏览器本地抽样。
- 构图能力扩展：补充 SQL 主外键、CSV、TXT 的分析和查询计划，支持显式的 SQLite 全量构图选项；TXT 语义提取增加分块、调用次数、重试和超时约束。
- 构图进度与传输：增加受限字段的进度信息，前端显示阶段状态；Nginx 对 JSON 等响应启用压缩，SSE 内容类型不进入压缩列表。

## 对现有 dev 功能的处理

保留 dev 的度数节点大小、蓝色主题、邻接高亮、点击选择、平移缩放、动态标签、搜索和有界 SVG 渲染。实际画布继续最多显示 180 个节点、400 条边；智能概览负责挑选更有代表性的内容。Schema 类型或关系非常多时也受该渲染上限保护，界面会报告未完整显示的数量。

保留全图度数与局部预览连接数的区别。数据稳定性比较避免对整份大图反复做 JSON 序列化。没有把来源分支的 800/2,000 默认展示额度直接套到 SVG 画布上。

## 审查发现与修复

| 问题 | 影响 | 修复 |
| --- | --- | --- |
| 来源分支覆盖了业务属性定位逻辑 | SQL/CSV 的 `properties.data` 业务列、包含点号的列名，以及名为 `table` / `data` 的业务列可能无法正确编辑；原有 10 项后端测试失败 | 恢复 dev 的属性定位、删除、迁移和溯源处理；前端实例编辑使用业务属性，Schema 仍读取完整原始属性路径 |
| 远端智能概览把全图边数作为获取上限 | 巨大图可能导致过量边数据进入内存 | 根据候选节点预算限制边数，并设置 200,000 条的绝对上限；超限返回已有结构化错误，不假装得到完整结果 |
| 相同度数的图可能抽出没有连边的样本 | 20,000 节点 / 100,000 边的验证图显示 180 个节点、0 条边 | 在类型配额内优先选取已选节点的邻居，保持稳定顺序和类型覆盖；修复后该图显示 180 节点、400 边 |
| Schema 自环和关系标签超出节点范围 | 点击“适应画布”后顶部关系标签被裁切 | 适应画布时计入实际 SVG 内容边界；测量只发生在适应操作中，不加入动画帧循环 |

另外，构图 HTTP 测试原先会间接调用开发环境中的真实模型服务。测试夹具已改为明确的本地构图模型端点，避免回归验证依赖外部供应商。
