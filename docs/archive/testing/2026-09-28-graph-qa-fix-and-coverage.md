## 修复与验证方法

- 工作区命令校验原来把所有带空白的参数再次按 shell 分词，导致 `python3 -c "print(1 / 2)"` 被当成绝对路径。新增真实 workspace 工具回归，区分 shell 命令正文与解释器参数、带引号的 here-document 数据；保持路径、受保护目录、嵌套 shell 和 fallback 恢复检查。
- FalkorDB 对不支持的 map 表达式仍返回原错误码，增加固定、无查询文本/凭据的修正提示（WHERE 筛选、独立返回列）。普通异常不公开原文，子查询不误报为 map。
- 方言参考把可执行的参数筛选、无向邻居示例提前；功能 skill 说明 `save_result` 为顶层工具参数，补充“总数相同只支持数量相同”。未加入全局上下文。
- 先跑失败回归，再修复；独立审查发现的 shell 选项和前置行边界也分别复现后补测。

问答统一经前端地址 `http://127.0.0.1:21108` 的 `/api` 代理发起，使用与前端相同的 chat 请求、SSE v2、模型版本和唯一请求 ID。真实模型为 `qwen3.6-plus`。主问答不调用 adapter、不直连数据库、不替换模型响应。
