# 远程问图审查问题 1、2、4 修复验证

基线为 feat/intelligent-graph-qa 的 6bd77a7。三个问题分别提交；第 3 项回答事实与查询证据不一致，仍保留为未解决问题，不据此合并 dev。

## 问题 1：延迟保存跨会话绑定

远程连接面板按用户、会话或草稿身份重建。浏览器历史导航改变上下文后，旧面板的未完成保存回调失效，不能把连接绑定到新会话。连接本身已保存时仍保留，不自动使用到别的会话。

真实 App 回归覆盖保存等待期间切换现有会话和新建任务；连接面板及 App 共 32 项通过。

## 问题 2：本地数据集按钮定位冲突

本地数据集入口增加独立稳定定位标识，原有浏览器场景使用该标识，避免与远程连接入口混淆。标准 pnpm test:e2e 的 25 项全部通过。

## 问题 4：完整结果交付

新增 export_remote_graph：一次调用完成查询、受限分页、结果完整性检查、CSV 生成与 Derived 发布。普通查询的完整长结果及明确保存的完整结果也自动发布，避免数据只留在 Ephemeral。聊天查询卡片提供所属会话的鉴权下载按钮；不依赖模型在自然语言中补链接。

分页查询要求外层 RETURN 按输出列中的唯一键 ORDER BY，可多列组合；禁止已有 SKIP、LIMIT、UNION，服务端保留分页参数。读取中检测重复排序键与列变化。整次操作共享行数、字节数和超时预算；中途失败、超限、取消、排序不满足或发布失败，均不能宣称已交付完整文件。查询读取成功但文件发布失败会单独报告 delivery_error。

完成指实际查询结果已交付，不证明模型选择了正确的查询口径，也不代表模型已经分析了文件每一行。分页读取不是同一时刻的事务快照，数据库期间更新仍可能影响结果，界面明确披露。FalkorDB 的服务端上限低于分页大小时会保守拒绝；不会放宽部署读取预算。CSV 对象/数组使用 JSON；公式形态字符串使用单引号转义。
