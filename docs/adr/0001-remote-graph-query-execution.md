# 通过原生查询工具扩展现有 Graph Agent

智能问图作为现有 Graph Agent 的新增能力，通过工具发现远程数据库结构、执行模型自主编写的原生查询，并复用工作区处理返回结果。选择这一边界，是为了保留模型解决问题的自主性，同时将连接和凭据使用集中在查询执行端；不采用让工作区脚本直接连接远程数据库的方案，现有工作区沙箱保持其网络隔离职责。

2026-09-26 更新：暂时取消数据库账号必须只读的接入要求。可写账号、无法读取权限元数据的账号均允许连接、保存和查询；Community 可用于本地测试。应用执行端仍通过单条查询、过程/函数入口约束以及 EXPLAIN 的只读类型检查阻止写入、结构变更和管理操作。不得把提示词、READ_ACCESS 或连接成功当作数据库授权证明。

连接可用与数据库权限核验分别返回。权限状态为 verified_read_only / not_read_only / unknown；未知不能宣称已验证，权限探测失败不能阻断正常读取。代价是可写账号不再具备数据库权限这一额外防护层，执行工具的拒绝测试必须独立验证。Cora 导入使用独立可恢复容器与数据卷，受限反序列化，凭据仅保存在本地私密配置。

面向模型的只读行为要求仅写入智能问图功能的 skill，不加入 Agent 全局上下文，以免把特定任务的约束带入其他任务。该 skill 指导 Agent 只查询源数据库，执行工具在模型偏离 skill 时仍独立阻止写入。
