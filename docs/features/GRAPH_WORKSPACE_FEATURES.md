# 构图、图探索与项目数据复用

## 数据集描述与 Schema

“创建你的图”中的 CSV 导入支持多表、复合主键及外键。数据集描述用于说明业务背景、字段含义及预期分析目标，可在构图面板和数据集列表中保存、修改。

Schema 视图中的节点代表实体类型／表结构，属性面板展示字段及 PK/FK 声明；实例数据与 Schema 分开展示。只有声明过的 PK/FK 才视为键约束，不根据字段名猜测主键。

会话实例图点击节点后，属性栏展示已加载的节点类型、业务字段和其他特征。CSV/SQL 行数据解包为原字段，元数据不会冒充业务字段；长值、数组和字段数量有显示上限。该面板不替代构图 Schema 的字段定义与键约束。

## 图画布探索

打开会话的图工作台后，可以通过自然语言查询定位相关节点，或者输入起终点查询最短路径。探索请求作为普通会话回合交给 Agent，查询当前会话的完整活动图；画布显示工具返回的有界子图及高亮。它不会在前端抽样图中近似计算最短路径。

探索需要可用的模型配置和已加载的实例图。当前回合未完成、会话等待审批或文件正在上传时，不发起新的查询。无匹配节点、节点歧义或无法找到路径时，应查看会话中的说明。“恢复全图”重新获取当前图的概览；大图仍受可视化预览上限限制。

可视化 MCP 入口兼容节点数组和高亮对象被模型提供方编码为 JSON 字符串的情况，严格校验后再转发；错误类型或非法 JSON 不会被当作空参数来展示全图。

## 帮助页面

侧栏“帮助”（`?view=help`）提供可搜索的工具和图学习模型清单。模型清单指图学习算法，不是聊天模型供应商列表。

## 项目加载已构图数据

1. 在“创建你的图”中完成个人数据集构图。
2. 新建或打开项目，进入项目数据集，点击“加载已构图数据”。
3. 按名称或描述搜索并选择源图，点击“加载到项目”。
4. 项目获得独立副本，包含源文件、描述、CSV PK/FK 元数据和完整构图结果。项目没有默认数据集时，副本自动成为默认数据集。

个人源图不会被移动或删除。修改或删除个人源数据集不影响已导入的项目副本；源图后续变更也不会自动同步到副本。仅能导入当前账号个人空间中已完成构图的数据，不会跨账号读取，也不会将其他项目数据绕过权限直接加载到当前项目。
