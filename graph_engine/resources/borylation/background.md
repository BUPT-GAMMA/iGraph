# 分子硼化反应示例：图背景与分析流程

这是 BO-01 的公开实验复盘。部署包已保存原始数据、派生记录与构图结果；不要重新构图或下载数据后才开始分析。当前没有运行原作者 GNN，不得把已报道产物称为模型预测。
当前会话绑定这张图时才使用此背景。用户切换图后停止沿用。回复语言服从本轮页面语言设置，不由本文件的中文决定。

## 图是什么
当前只加载交付包第一张 BO-01 分子结构图：22 个重原子、24 条无向化学键，使用 48 条双向存储边。其余七张分子图不加载。产物、配体、溶剂和 96 条实验保留为背景元数据，由 borylation_case_analysis 读取，不是图节点或第二张图。工作台仅展示 BO-01 分子结构；不要请求切换到记录关系图，也不要把产物或实验 ID 传给图节点操作工具。
所有显示位点编号从 1 开始，atom_index 从 0 开始；节点 ID 是 BO-01:atom:{atom_index}。前端化学结构和点击原子均使用这套映射。

## 分子环的结构核对
structure 工具现在从保留的 chemical_bonds 计算 rings 与各候选原子的 ring_memberships。
使用显示编号描述：4、5、6、7、13、14 为一个六元芳香碳环；8、9、10、11、12 为含 2 个 C、2 个 N 和 1 个 S 的五元芳杂环，其中 9 是 C–H 候选；15、16、18、19、20、21 为另一六元芳香碳环。
不得把含硫的五元环说成 triazole / 三唑，不得把 9 号位点放入苯环。正式命名不是本例任务，使用工具提供的环大小、元素组成和位点编号即可。
这些资料仅帮助阅读；当前图的 rings、候选记录为本轮证据。

## 四问 workflow
先读取 molecular-analysis-workflow 技能。每轮调用 borylation_case_analysis 对应 step，使用当前图的工具结果，不用历史数字替代本轮读取。
1. properties：读预存的 RDKit 结构描述符及方法。当前包没有溶解度或毒性测定，未运行两类预测模型。反应记录含 THF、环己烷、二氧六环、乙腈、NMP、2-MeTHF 等，仅证明做过这些溶剂条件筛选，不能证明完全溶解。两个只有 CAS 的溶剂保留 CAS，不猜名字。可以按结构给出标明假设的溶剂选择理由；毒性未知不等于无毒。
2. rings：按化学键计算环，按大小、元素组成和芳香性分类。当前三个环分为两种粗类型：两个六元芳香碳环和一个含 C2/N2/S 的五元芳杂环。每个环的取代环境分别解释。
3. structure：读芳香 C–H 候选；需要标注时实际调用 highlight_nodes / visualize_subgraph。用 atom_index 对应真实节点 ID，以 display_number 展示；工作台中的高亮映射到分子结构。
4. symmetry：按完整分子对称类合并。symmetry_class 是内部标识，按 display_numbers 列等价组与代表，不把绘图位置相似当对称。
后续自由追问仍可使用 products、conditions、plan，读取已报道产物、96 条记录或历史条件复核草案。

## 事实边界
- binary=1 的四条记录达到单硼化转化率 5% 阈值；binary=0 是未达到阈值，不等于零转化。八条非零记录中四条低于阈值；这个标签口径不能直接外推其他底物。
- 产物表与条件表来自不同任务，只按底物关联。缺少产物与条件逐条实验对应，不能说三个产物来自这 96 组实验，也不能指定某条条件对应哪个位点或声称它们同时形成混合物。
- 单硼化转化率不等于位点选择性或分离收率；没有报道某位置不等于验证该位置不反应。
- 本次达标记录均使用环己烷仅为观察结果，不代表必要条件或溶剂机制。
- 配体使用工具中的简称或 CAS，催化剂保留原始当量，不猜名称、取代位置或金属中心 mol%。
- 开头给一句结论，之后正常解释，结尾保留总结。扩写可以帮助解释，但不得把假设作为实验结果。
